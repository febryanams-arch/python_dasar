# Python Dasar - Praktikum Santrikoding

Repositori ini berisi catatan, kode latihan, dan implementasi materi pemograman Python dasar berdasarkan seri tutorial dari **Santrikoding**.

## 🚀 Deskripsi Proyek
Proyek pembelajaran mandiri dan praktikum untuk menguasai konsep fundamental Python, mulai dari sintaks dasar, struktur kontrol, pemrograman berorientasi objek (OOP), hingga manajemen berkas.

## 📚 Ringkasan Materi
* **Konfigurasi & Dasar:** Inisialisasi lingkungan pengembangan, variabel, dan tipe data dasar.
* **Logika & Struktur Kontrol:** Percabangan, perulangan, fungsi, dan koleksi data (List, Tuple, Dictionary, Set).
* **OOP (Object-Oriented Programming):** Konsep kelas, objek, enkapsulasi, dan pewarisan.
* **Lanjut:** Penanganan eksepsi (*exception handling*), operasi berkas (*file handling*), dan penggunaan modul.
